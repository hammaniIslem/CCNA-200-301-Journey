==================================================   UnEven Networks   =================================================================================================


the Problem :

lets observe this topology


            .1.0/24       g0/1                                      g0/1       .4.0/24
		---------------           .1           .2              ---------------
            .2.0/24       g0/2  \       g0/0          g0/0       /  g0/2       .5.0/24 
	       ----------------- router1 -----------------router2 ----------------- 	
            .3.0/24       g0/3  /          192.168.0.0/24        \  g0/3       .6.0/24	
		---------------                                    ---------------


in the connection of these routers we used 7 Networks, one of them used to connect the two Routers

but are we actually using all the host we reserved? lets see

on Network 192.168.0.0/24 we have :

				Network address : 192.168.0.0
				broadcast address : 192.168.0.255
				Router1's G0/0 address : 192.168.0.1
				Router2's G0/0 address : 192.168.0.2

so from 8 bits of host portion we only used 4 addresses , leaving 

			256 - 4 = 252 non usable addresses



so in addition to the rising number of devices , we also have unusable addresses on each Network 
 
---------------------------

another example :


a company needs a network fit for 5000 host , so they get a class B address from
		
			 - IANA - Internet Assigned Numbers Authority -

the problem is class b have 65536 addresses 

				65536 - 5000 = 60536 non uable addresses


so we need another addressing architecture to avoid this much of wasted address




=====================================       CIDR      =================================================================================================


in 1993   - IETF - Internet Engeneering Task Force - gave a Solution :

		CIDR - Classless Inter-Domain Routing 


so instead of relying on /8 , /16 , /24 classes

, we use all the nubers in between to have more flexible Network/Host portions

allowing Bigger Networks to be split to smaller Networks called  - Subnets -


-------------------- /24 -----------------------------------

using our previous example : 192.168.0.0/24

we need a Network that supports only  2 hosts

in binary :

		   NetworK             |   Host

 	11000000   10101000   00000000   00000000 
	   192   .    168   .     0    .     0


        11111111   11111111   11111111   00000000
           255   .    255   .    255   .     0

	
 		8 bits of Host Portion

		2⁸-2 = 254 host   ------------> 252 wasted



-------------------- /25 -----------------------------------

to split the Network we take a bit from the Host and add it to the Network Portion 


so instead of /24 it becomes /25


		   NetworK                |  Host

 	11000000   10101000   00000000   0 0000000

        11111111   11111111   11111111   1 0000000
           255   .    255   .    255   .    128

	
 		7 bits of Host Portion

		2⁷-2 = 126 hosts   ------------> 124 wasted
 

we keep splitting till we get a fitting Network

this is the best split for the example we have, a simple Network with only 4 addresses
2 reserved for Network and Broadcast and 2 for the actual Interfaces that connect the two Routers

 192.168.0.0/30 means 

		192.168.0.0  -------> Network address
		192.168.0.1  -------> Router1's interface address
		192.168.0.2  -------> Router2's interface address
		192.168.0.3  -------> broadcast address
	

in binary 

		11000000.10101000.00000000.000000 00  -------> Network address
		11000000.10101000.00000000.000000 01  -------> Router1's interface address
		11000000.10101000.00000000.000000 10  -------> Router2's interface address
		11000000.10101000.00000000.000000 11  -------> broadcast address

=============================    Subnet Split   =======================================================

we want to devide the Nework to 4 switches each has 45 hosts

so we received this Network from IANA  192.168.1.0/24 

how can we split it into 4 subnets



1/ first we make sure the 8 bits is sufficient for al hosts 

 each subnet has 45 plus 2 for Network/broadcast 

so 47 addresses by subnet

                            47 * 4 = 188

so no problem in the nember of hosts



2/ lets start with  /30  and go up    
	
	/30 		2²-2 = 2   < 45

	/29 		2³-2 = 6   < 45

	/28 		2⁴-2 = 14   < 45

	/27 		2⁵-2 = 30   < 45

	/26 		2⁶-2 = 62   > 45


/26 has 62 usable addresses , so it's the most fitting for this situation


yes /26 still has some wasted addreses , but it gives us some space for future growth
