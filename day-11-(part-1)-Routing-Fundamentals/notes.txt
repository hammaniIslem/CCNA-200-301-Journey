Routing is the proccess to forward the iP Packets to their Proper Destination 

just like Switches using the - MAC address-table - to do the Switching

Routers use - Routing Table - to find the best Route
 
there are two Main Methods to Learn a Route:

	1/ Static Routing

by manually adding the Route to the Table 

	2/ Dynamic Routing

by using one of th Routing Protocol to Detect new Routes (OSPF,RIP,EIGRP..)


====================================      Routing Table     ==============================================================

how does a Routing Table operate ?

When Receivig a packet , the Router searches for a match in the Table

and chooses between the three options 
	
	1/ Forwarding the Packet to the Route he found to the next hop
	2/ accept and decapsulate the Packet if the Destination is his own
	3/ drop the Packet if there are no Matches

if there are no matches the Router never Floods the packet

to show the Routing Table on a Router we use 
	
	R1# show ip route


codes : L - local, C - connected, S - static, R - RIP, M - Mobile, B - BGP
       	D - EIGRP , EX - EIGRP external , O - OSPF , IA - OSPF inter area
	N1 - OSPF NSSA external type1, N2 - OSPF NSSA external type2
	E1 - OSPF external type1, E2 - OSPF external type2
	i - IS-IS inter area ,* - candidate default, U - per-user static route
	o - ODR, P - Periodic downloaded static route, H - NHRP , l-Lisp
	a - application route
	+ - replicated route, % - next hop override, P-overrides from PfR

Gateway of last resort is not set

---------------------------------------------------------------------------------------------------------------------------------------

the codes represent an Explanation on the Letter on the Left


here we see Two routes for each IP we added to the interface 

C  means that the whole Network is accesible through that Port
 
L  is a /32 , pointing to the interface itself , so when the Destination matches that route 
the packet gets sent to the interface which is the same Router ,so he accepts the packet 



- actually when the Destination is /32 , it also matches the C routes because it's a part of the same Network
but the Router Chooses the most specific route Possible 

192.168.1.0/24  --> 256  could match (from 0 to 255)
192.168.1.1/32  --> only the interface 

most specific = longst Prefix length
