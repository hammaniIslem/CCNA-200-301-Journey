Name feild is the same as description 

Vlan feild will be explained in an other video (trunk meaning included)

duplex is for the way the switches send data(half , full aor auto)
half duplex means only one device can send ata time 
full duplex means both can send at the same time 
auto means the switch will negotiate with the neighbor device and choose between half and full
the defaut is auto , changes to a-full or a-half after negotiation
 
speed is corresponding to the BASE-T
for example 10/100/1000BAse-T will have these options :
either 10 , 100, 1000 or auto 
auto means the switch will negotiate with the neighbor device and choose the appropriate speed for both devices
changes to a-10, a-100, a-1000 after negotiation

========================================   Half Duplex and Full Duplex   ===============================================================

Half Duplex is the ability to send data only in one direction at a time which means the other device has to wait

Full Duplex is the ability to send data both ways at the same time 


logically Full duplex is the best option

but where would half duplex be used?


========================================     Hubs     ==========================================================================


the hub is an old technology used befote the switch , with the same purpose 
, connecting end hosts to the same domain
 
hubs are known to be dumb devices ,because he doesn't use Mac addresses to send data
instead they broadcast the message to all devices ,only operating at the Layer 1

 
---------------------------------------    Collision    ------------------------------------------------------------------------------
	
	 __________________________________________________________________________
	|                                                                          |
	|   Collision Domain                                                       |
	|                                                                          |
	|                                                                          |
	|	pc1   ---------------------  Hub -------------------- Pc2          |
	|				      |                                    |
	|				      |                                    |
	|				      |                                    |
	|				     pc3                                   |
	|__________________________________________________________________________|
	

if pc1 and Pc2  want to send a message at the same time ,the send their messages normally on the port connected to the hub 
but a problem occures when the hub floods it (pc1's message and Pc2's message both going to pc3 at the same time)
we call that a collision

because the message is ment to be sent to all devices Connected to the hub in the Same Domain
we call it a Collision Domain



ethernet devices use what's called:
  
			CSMA/CD (Carrier Sense Multiple Access with Collision Detection) 

before Sending frames, devices listen to the Collition Domain to detect if other devices are sending messages 
if a collision occurs the device send a jamming signal to inform othe devices that a collision happened 
then each device has to wait a random time before it can listen again


---------------------------------------    Switches    ------------------------------------------------------------------------------


	 __________________________________________________________________________
	|                                                                          |
	|   Broadcast Domain                                                       |
	|                                                                          |
	|                collision domain             collision domain             |
	|	pc1   --------------------- switch  -------------------- Pc2       |
	|				      |                                    |
	|				      |  collision Domain                  |
	|				      |                                    |
	|				     pc3                                   |
	|__________________________________________________________________________|


Switches use Mac Addresses to send data to a speciffic address 
, also they never try to send two Frames at the same time 

	one device + one packet = no collision 

this one device connected to the switch is their own Collision Domain

and because of that devices now can finally reach the full Duplex transmission

========================================  interface Errors   ===============================================================

we already seen the command	
			
			Switch#show interfaces 

here are the meaning of some labels on the output

- packet input , bytes : 
counts how many packets passed by the device , and their size in bytes

- runts : frame that re less than the minimum size 64byte

- giants : frame that re less than the maximum size 1518byte

-cRc :frames that failed the crc check(in FCS frame Triler)

-Frame : frames that had inncorrect format(due to an error)

-input error : Total of various errors , counting the four before

-output error :frames the switch tried to send and failed due to an error



these labels are the same on a router
