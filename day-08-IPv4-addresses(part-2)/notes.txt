===========================================     maximum hosts on a Network     ===========================================================

-------------------------------------------     class c   --------------------------------------------------------------------------------


example :  192.168.1.0/24   the host portion is 8

		2⁸ = 256

    but we discussesd earlier that the first address is an indicator for the Network 

				192.168.1.0

    and the last one is an id=ndicator for the broadcast 

				192.168.1.255

    that gets us :  

		2⁸ - 2  = 254

    all class c networks has 254 hosts


the first address usable is the one after the Network address  :   192.168.1.1/24

the last address usable is the one before the broadcast address : 192.168.1.254/24

-------------------------------------------     class B   --------------------------------------------------------------------------------


example :  172.16.0.0/16   the host portion is 16

		2¹⁶ - 2 = 65534

    all class B networks has 65534 hosts



the first address usable is the one after the Network address  :   172.16.0.1/16

the last address usable is the one before the broadcast address : 172.16.255.254/16

-------------------------------------------     class A   --------------------------------------------------------------------------------


example :  10.0.0.0/8   the host portion is 24

		2²⁴ - 2 = 16777214

    all class A networks has 16777214  hosts


the first address usable is the one after the Network address  :   10.0.0.1/8

the last address usable is the one before the broadcast address : 10.255.255.254/8

to show the current interfaces info we use :

			router# show ip interface brief


    Interface 		 IP-ADDRESS  	OK? 	Method 	   Status 		   Protocol
    GigabitEthernet0/0   unassigned     YES     unset      administratively down   down
    GigabitEthernet0/1   unassigned     YES     unset      administratively down   down
    GigabitEthernet0/2   unassigned     YES     unset      administratively down   down
    GigabitEthernet0/3   unassigned     YES     unset      administratively down   down


OK? feilsd is a Legacy feature to make sure the ip address is valide or not
modern devices don't allow invalid IPs to be assigned at all ,so it's always YES

Method feild is to identify whether the ip was set -Manual- or was obtained via a -DHCP- server
,
status is the default state of the port 
status is for the Layer 1 ,to see if the device is physically connected
the router's ports are by default -administativaly down- and must use               router(config -if)# no shutdown
the switch's ports are by default -administativaly up-

protocol feild indicateds if the port is functionnally down or up

a port status can be up while the protocol is down


-----------------------------------------   configure an interface   ----------------------------------------------------------------

	Router(config)# interface gigabitethernet 0/0
	Router(config-if)#

	Router(config-if)# ip address 192.168.0.254 255.255.255.0

	Router(config-if)# no shutdown
