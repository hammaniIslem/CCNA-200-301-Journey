
to navigate in the internet the devices require an ip address

the common type are IPv4 addresses


			192.168.10.254 / 24

	 	   192  .   168  .   10   .   254            decimal
		11000000 10101000 00000001 11111110          binary

the address is made in 4 feilds each of 8 bits	 

			max number in a feild is 255

----------------------------------  host / network ------------------------------------------------------------
 

the /24 prefix indicates the bits reserved for the network part ,the rest is for the host

example : 	11000000 10101000 00000001 11111110   /24
		   192  .   168  .   10   .   254     /24

		192.168.10  is the network part
		
	    	.254 is the number of the host


example :	10011010 01001110 01101111 00100000   /16
		   154  .   78  .   111   .   32      /16

		154.78 is the Network 

		.11.32 is the host portion


example :       00001100 10000000 11111011 00010111    /8
		   12   .   128  .   251  .   23       /8

		12.128.251 is the Network 

		.23 is the host portion
 
==============================================  IPv4 classes ===========================================================================

the IPs are separeated in 5 classes


	| class | First octet | First decimal range | 

	|   A   |   0xxxxxxx  |        0-127        |       	
	|   B   |   10xxxxxx  |       128-191       |       	
	|   C   |   110xxxxx  |       192-223       |        	
	|   D   |   1110xxxx  |       224-239       |       	
	|   E   |   1111xxxx  |       240-255       |       	


the classes actually used are A, B and c

class D is reserved for multicast adressing (Later Topic)

class E is reserved for Expirimentall uses 

------------------------------------------- 127.0.0.1 -------------------------------------------------------------

in class A the 127 is never used in actual networks 

		127.0.0.0 - 127.255.255.255

127 is reserved for loopback (testing the osi stack on the local host)

	ping 127.0.0.1 is sent to the same local host 


	| class | First octet | First decimal range |  prefix lenght

	|   A   |   0xxxxxxx  |        0-127        |    /8   	
	|   B   |   10xxxxxx  |       128-191       |    /16    	
	|   C   |   110xxxxx  |       192-223       |    /24


	class A only uses /8 
	class B only uses /16
	class C only uses /24


the previous examples we used :
	
	192.168.10.254 /24 	class c
	154.78.111.32  /16      class B
	12.128.251.23  /8	class A


---------------------------------    class size     ---------------------------------------------------------------------------

class A :  has only 7 bits for Network (8-1 of the 0)	(2⁷ networks = 128)
	       and 24 bits for Hosts 			(2²⁴ hosts = 16777216)

class B :  has 14 bits for Network (16-2 of the 10)	(2¹⁴ networks = 16384)
	       and 16 bits for Hosts 			(2¹⁶ hosts = 65536)

class C :  has 21 bits for Network (24-3 of the 110)	(2²¹ networks = 2097152)
	       and 8 bits for Hosts 			(2⁸ hosts = 256)


--------------------------------       Netmask      ------------------------------------------------------------------------------

net maslk is just another way to write the Network portion 
		by replacing it with all 1s 
		and replacing the host portion with all 0s

=======================================  Network and Broadcast address   ==============================================================


---------------------------------------------  Network address  ---------------------------------------------------------------

when the host portion is all 0s it means it's the network address, an identifier for the network
it can't be assigned to any host

the first address usable is one address after the Network address

			192.168.10.0 / 24 Network address
			192.168.10.1 / 24 first usable address in the network


---------------------------------------------  broadcast address  ---------------------------------------------------------------

when the host portion is all 1s it means it's the Broadcast Address
also can't be assigned to a host

the last address usable is one address before the broadcast address

			192.168.10.255 / 24 broadcast address
			192.168.10.254 / 24 last usable address in the network


broad cast is to send data to all hosts connected 

				in the frame we use:

				Dist ip :192.168.10.255
				Dist MAC: FFFF.FFFF.FFFF
