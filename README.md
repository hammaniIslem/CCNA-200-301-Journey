## CCNA 200-301 Journey

My personal learning journey to get the **Cisco Certified Network Associate (CCNA 200-301)** certification,
following [Jeremy's IT Lab](https://www.youtube.com/@JeremysITLab).

This repository documents my progress through the course, practical networking exercises, Cisco IOS configurations, Packet Tracer labs, and personal study notes.

## Objectives

- Understand networking fundamentals and TCP/IP.
- Learn Cisco IOS command-line configuration.
- Practice switching and routing.
- Understand IPv4, IPv6, and subnetting.
- Configure network services and security.
- Develop troubleshooting skills.
- Prepare for the CCNA 200-301 certification exam.

## Tools & Resources

 Cisco Packet Tracer | Network simulation and labs 
 Anki                | Spaced repetition and flashcards 
 Jeremy's IT Lab     | Main CCNA learning resource 

## Practical Labs

Each lab will include:

- Objectives and requirements
- Network topology
